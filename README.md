# Кэшбэк — категории банков (Android)

Подсказка на кассе: в какой категории какие банки дают кэшбэк и сколько процентов.
Данные хранятся только на телефоне, без аккаунтов и сети.

## Что умеет

- **Главный экран:** переключатель текущего и следующего месяца. Категории в заданном порядке,
  выбранные выше; в строке все банки с процентом в общем порядке банков («Т-Банк 5% · Альфа 3%»).
  Невыбранные — в сворачиваемом блоке «Без кэшбэка».
- **Категория:** у каждого банка поля «Постоянно» и «В этом месяце». Банк выбран, если заполнено
  хотя бы одно поле. Месячный процент перекрывает постоянный. Сохраняется сразу.
- **Меню ⋮ → Категории / Банки:** добавление, удаление (вместе с привязками, с подтверждением),
  порядок перетаскиванием за ☰; категории можно переименовывать.
- **Смена месяца:** 1-го числа следующий месяц становится текущим, прошедший удаляется.
- Процент — до одного знака после запятой, от 0,1 до 100.

ТЗ: `spec-cashback-v1.md` в проекте «Личные приложения под Андроид» на claude.ai.

## Сборка

Открыть папку в Android Studio или выполнить:

```
./gradlew assembleDebug        # APK: app/build/outputs/apk/debug/app-debug.apk
./gradlew testDebugUnitTest    # тесты (Robolectric, первый запуск докачивает окружение)
```

## Стек

Kotlin 2.0.21, Jetpack Compose (Material 3), Navigation Compose, Room 2.6.1 (KSP), MVVM, ручной DI,
[Reorderable](https://github.com/Calvin-LL/Reorderable) для перетаскивания. minSdk 26, targetSdk 35.

Имя пакета `com.example.cashback` временное — перед публикацией в Google Play его нужно заменить.
